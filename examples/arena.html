Arena

A round robin between the five strength levels of the play page: one ply, 500 nodes, 5000 nodes, 50000 nodes and a fixed time per move. Each of the ten pairings gets two workers, one per side, so all ten games run at once and the crosstable fills in live. Two workers rather than one because with a shared hash table the weak side would play with the strong side's deep analysis. Colours alternate between games. Every game opens with four random legal plies, otherwise the engine would repeat the same game each time. Cells show the row level's wins, draws and losses against the column level, coloured by score. Games end by checkmate, stalemate, threefold repetition, the fifty move rule, insufficient material or a 300 ply cap, all checked by the page from the board the engine prints. A level should not lose its mini match to the level below it, and the summary counts how many do not.
