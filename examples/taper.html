Tapered piece square tables

One heat map per piece showing the piece square table values Naddu actually uses at a given game phase. The tapered eval blends the middlegame (mg) and endgame (eg) tables with (mg * phase + eg * (24 - phase)) / 24, where the phase counts the pieces on the board for both sides: knights and bishops 1 each, rooks 2, queens 4. So 24 is the start position (pure mg), 0 is kings and pawns only (pure eg) and, say, a rook ending is 4. Drag the slider to watch the blend. The tables are fetched from the engine with the pst command, so if you edit them in naddu.js this page follows. Boards are from white's side with rank 8 at the top, red is good for the piece and blue is bad, on one colour scale shared by all six boards and fixed across all phases.
