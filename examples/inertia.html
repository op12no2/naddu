Inertia

How much does each number matter? Every value of every search parameter, or every eval feature other than the piece square tables, is nudged down and then up by a percentage of its default, at least 1, and the Strategic Test Suite is run each time. The table shows the change in the STS score against a baseline run with the defaults, and the change in the nodes searched. At a fixed depth the engine is deterministic, so every difference is real however small, but anything that prunes less looks better at a fixed depth simply because it searches more, so read the score change together with the node change. A value that loses in both directions sits in a dip, that is the inertia. A value that gains in one direction is worth pointing the walk at. STS measures move choice in quiet positions, not strength, so treat it as a map rather than a verdict. The time list never moves here, it only applies with a game clock. The positions are shared with the sts page through sts.js.
